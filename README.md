# 🖨️ Printzer

**Printzer** is a user-friendly website that allows users to conveniently order Xerox and print copies online. Users can select the type, size, and quantity of their prints — making the entire process smooth, customizable, and accessible from anywhere.

---

## 🚀 Features

- 📄 Upload documents to be printed
- 🖨️ Choose print type: black & white or color
- 📐 Select paper size: A4, A3, custom sizes
- 📑 Options for single or double-sided printing
- 📦 Choose quantity and binding options
- 💵 Pricing calculator based on selection
- 🧾 View and track order history (future enhancement)
